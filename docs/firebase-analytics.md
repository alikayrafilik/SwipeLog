# Firebase Analytics setup

SwipeLog uses `@react-native-firebase/app` and `@react-native-firebase/analytics` for native Firebase Analytics.

## Required Firebase files

Native analytics builds need the platform config files from Firebase Console:

- Android: `google-services.json`
- iOS: `GoogleService-Info.plist`

These files contain project-specific app identifiers and are not generated by the app code. Add them through the normal Expo/EAS secret or config-file workflow for the target build environment.

The dynamic Expo config reads the EAS file variables below:

- `GOOGLE_SERVICES_JSON` for Android
- `GOOGLE_SERVICE_INFO_PLIST` for iOS

For local Android prebuilds, place an ignored `google-services.json` file at the repository root. Never commit either native Firebase config file.

## Runtime behavior

Analytics is enabled by default. Set this environment variable to disable all analytics calls:

```bash
EXPO_PUBLIC_ENABLE_ANALYTICS=false
```

The app uses `src/services/analytics.ts` as a safe wrapper. If the native analytics module is unavailable, such as in Expo Go or an incomplete native build, calls become no-ops instead of crashing the app.

## Privacy rules

Analytics events must not include email, username, bio, raw search queries, review text, profile URLs, or friend identifiers. Prefer counts, booleans, source names, and coarse buckets.
